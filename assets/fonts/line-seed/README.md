# LINE Seed KR

- Source: https://seed.line.me/index_kr.html
- Official archive: https://seed.line.me/src/images/fonts/LINE_Seed_Sans_KR.zip
- Archive folder: `LINE_SeedKR_2023.09.06`

The original, unmodified TTF files are bundled with the application:

- `LINESeedKR-Rg.ttf`: Regular, body text, helper copy and memo input.
- `LINESeedKR-Bd.ttf`: Bold, headings, amounts and primary actions.

The app loads these local assets with `expo-font` before mounting its screens.
No runtime font download is needed. These are the complete original fonts,
not the subset files used in the earlier comparison mockup.

Provider-branded social login buttons and native system controls retain their
existing typography.
