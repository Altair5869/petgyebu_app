# F-M06 따뜻한 홈 Implementation Plan

> **최신 작업 범위:** 사용자 지시에 따라 Codex는 ui-ux-pro-max를 사용한 디자인만 담당하고, QA는 Claude Code가 담당한다. 아래 이전 검증 기록은 인계 참고용이다.

## 후속 승인: 공통 스타일 확대

- 후속 로그인 연출 승인: 기존 두 캐릭터 뒤에 살구색 타원 배경과 작은 점 두 개를 추가하고 높낮이·크기에 소폭 차이를 둠. 브랜드명 → 펫 장면 → ‘펫과 함께 쓰는 작은 소비 기록’ → 보조 설명 순서. 로그인 버튼 위에 ‘함께할 펫을 만나보세요’ 배치. 기존 ScrollView·소셜 로그인 버튼·인증 동작 유지. 장식은 접근성 트리에서 숨김. 이번 변경 후 실행 화면 확인·QA는 진행하지 않음.

- 후속 글꼴 승인: 비교 후보 중 LINE Seed KR 적용. 공식 배포 ZIP의 원본 Regular·Bold TTF와 SIL OFL 전문을 `assets/fonts/line-seed/`에 포함함.
- `src/theme.ts`의 `fonts.regular`·`fonts.bold`를 앱 텍스트·금액 입력·메모·내비게이션 헤더에 적용. 임의 600/700 굵기 합성 대신 실제 Bold 파일 사용. 소셜 로그인 브랜드 버튼과 OS 날짜 선택기 등 시스템 UI는 기존 글꼴 유지.
- 루트 `useFonts`에서 로컬 두 파일을 로드한 뒤 화면을 마운트. 로드 실패 시 시스템 글꼴의 안내 화면을 표시하고 스플래시를 닫음. 기존 세션·API·라우트 로직 변경 없음.
- 글꼴 변경 QA 인계: 콜드 스타트의 글꼴 로딩/실패 안내, iOS·Android 헤더와 입력창, 확대 글자·긴 금액·한글 메모 줄바꿈 확인 필요. 이번 변경 후 lint·typecheck·Jest·Maestro·시뮬레이터 확인은 실행하지 않음.

- 후속 홈 문구 수정: 게이지 아래 시각적 ‘남은 예산’ 캡션 제거. 잔액 카드의 접근성 설명 유지. 기존 네 상태 분기를 유지하며 `PET_STATE_COPY` 안내 문구를 편안함·살펴보기·걱정·놀람으로 조정. 상태 기준과 게이지 계산 변경 없음. 이 문구 변경 후 QA는 실행하지 않았으므로 기존 문구를 직접 검사하는 테스트·Maestro 시나리오는 Claude Code에서 확인 필요.

- 요청: 홈에서 승인한 밀크 크림·코코아·살구 스타일을 로그인·지출 기록·통계·설정에 적용.
- `src/theme.ts`에 공통 색상과 본문 최대 너비를 정의하고 홈도 같은 색상을 참조하도록 연결.
- 로그인: 크림 배경, 기존 CAT/DOG 그림, 코코아 제목, 작은 화면용 스크롤. 카카오·구글 브랜드 색상과 로고 유지.
- 지출 기록·수정: 흰 금액 입력 카드, 큰 숫자, 살구색 카테고리 선택, 흰 메모 입력, 코코아 저장 버튼. 기존 날짜 선택기 동작 유지.
- 월별 통계: 흰 요약·카테고리 카드, 차분한 카테고리 색상, 금액 고정폭 숫자, 줄바꿈 가능한 요약 항목과 내역. 월 이동 버튼 터치 영역·눌림 반응 정리.
- 설정·예산 변경: 흰 카드, 살구색 선택 및 보조 버튼, 별도 위험 동작 색상. 로그인 후 펫 선택·초기 예산 설정에도 같은 색상 적용.
- 공통 버튼 최소 높이 56, 모서리 16, 카드 모서리 24. 로딩·오류 화면과 내비게이션 헤더도 같은 팔레트 적용.
- API·인증·입력 검증·금액 계산·라우트·삭제 확인 동작 변경 없음. 의존성 추가 없음.
- QA 인계: 이번 확대 변경 후 lint·typecheck·Jest·Maestro·시뮬레이터 확인은 실행하지 않음. 아래 이전 검사 결과와 스크린샷은 이번 변경을 검증하지 않음.
- 이번 작업에서는 테스트·Maestro 파일을 수정하지 않음. 해당 파일의 작업 트리 변경은 이전 홈 작업에서 남아 있는 내용임.

**Goal:** 승인된 A안의 홈 구성에 최종 승인된 밀크 크림·코코아·살구 팔레트를 적용해 펫·금액 가독성과 빠른 지출 기록을 개선한다.

**Architecture:** 기존 Home API, 세션 분기, 화면 재진입 갱신을 유지한다. 홈 전용 스타일과 펫 표시 크기만 조정하고 입력·통계·설정 화면은 기존 경로로 연결한다.

**Tech Stack:** Expo 58, React Native 0.88, Expo Router, expo-image, Jest, Maestro.

**Spec:** 2026-10-22 대화에서 사용자가 승인한 A안. 제품 계약은 docs/00-renewal-development-guide.md의 F-M06 홈 기준.

## Global Constraints

- 최종 승인 색상: 배경 #FBF8F3, 카드 #FFFFFF, 버튼 #765344, 본문 #382D28, 보조 문구 #786B63, 보조 영역 #F7E6D8. 초기 크림·초록 팔레트를 대체함.
- 기존 CAT/DOG 각 네 상태 자산 유지. 펫 → 잔액·사용률 → 기록 순서.
- 기존 게이지는 남은 예산 비율. 100% 이상에서는 비움. 상태는 서버 petState 사용.
- 남은 예산 또는 초과 금액 라벨과 32–36pt 금액을 분리. 정확히 100%는 남은 예산 0원.
- 하단 기록 버튼은 safe area 안, 스크롤 본문과 겹치지 않음. 기존 접근성 라벨과 경로 보존.
- 지출 0원 안내, 로딩·오류·재시도, 409 분기 유지. 신규 의존성 없음.
- API: GET /api/v1/home, 기존 지출 POST 및 통계·설정 이동만 사용. 계약 변경 없음.

## Review Focus

- 긴 금액: 100,000,000원 이상 합계도 누락·가림 없이 읽을 수 있어야 함.
- 글자 확대·작은 화면: 스크롤과 하단 기록 버튼 접근 가능.
- 정확히 도달 vs 초과: 0원과 절댓값 초과를 구분하고 사용률을 100%로 제한하지 않음.
- CAT/DOG 네 상태: 기존 자산과 게이지 관계 유지, 상태를 색에만 의존하지 않음.
- 기록 후 복귀·새 달·연결 실패: 기존 새로고침과 진입 분기 유지.
